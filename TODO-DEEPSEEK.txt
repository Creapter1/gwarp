HOW THE LAB WORKS
1. Research the job (how Scratch / TurboWarp / PenguinMod do it, with links).
2. Write AT LEAST 3 DIFFERENT versions of the same code: A, B, C.
   Different on purpose: e.g. A = simplest, B = fastest, C = safest/most
   complete. Each is a self-contained module  (() => { 'use strict'; ... })();
3. EXPERIMENT on paper: for each version, walk through tricky inputs and
   write what happens. Include a console test for each version.
4. Write a LAB REPORT table: speed, safety, size, Scratch-accuracy,
   risks -> and pick a WINNER (or say "mix A+C").
5. Files: deepseek/<job>-A.js, -B.js, -C.js, deepseek/LAB-<job>.txt
6. Claude later runs real tests with 3 agents (one per version) and
   merges the best parts into G-Warp.
Rules from TODO.txt always apply. Never rewrite app.html. Say "UNSURE:"
instead of guessing about G-Warp functions.
