Changelog

This is a short summary of release milestones recorded in the project's team log. It is not a complete list of every code change.

  • Beta v15.67.0 (23 Nov 2026): Big map: put your own sprites on the map. The player makes the camera follow it, and world objects (enemies, coins) stay in their spot on the map. Every frame the map and the sprites draw with the same camera, so nothing slides. SVG 360: Play shows the turn before you make it, a lean or half turn can be made instead of a full turn, and a My Block "show ... at angle" picks the right frame for any angle. Plain Scratch blocks, Developer mode only.
  • Beta v15.66.0 (23 Nov 2026): two new Developer-mode tools in the Costumes tab. SVG 360 turns a vector costume in 3D (X, Y or Z axis) and adds the frames as new costumes; Sparky is the default. Big map builds giant maps that scroll in X and Y, plus parallax side layers, from one picture; it adds plain Scratch blocks (no extensions), so the project also runs in Scratch. Undo and Redo work for both.
  • Beta v15.65.0 (22 Nov 2026): .sb3 files keep eight Scratch blocks that were left out before (go to sprite/mouse, change/set effect, change/set sound effect, clear sound effects, set drag mode, username); renaming a variable also renames it inside other blocks; deleting a variable removes it from the blocks it was used in; one Undo brings back a renamed or deleted variable.
  • Beta v15.64.0: every gallery extension was tested: 159 of 183 load, and one broken extension no longer holds up the others; more TurboWarp/PenguinMod extension features work (Font Manager, Timers, Tween, Messages Plus, ZIP); the editor uses less CPU when idle.
  • Beta v15.63.0: code-area fixes found with an automatic mouse tester: dropping a reporter on a full slot no longer deletes blocks (the old reporter pops out next to it); Undo keeps typed values; answer, username and other reporters have the right round/pointy shape; Animation tab bones can hang beside a body (shoulders, hips), get automatic names, and work with the Ready-made moves.
  • Beta v15.62.0–15.62.1: "run without screen refresh" runs for up to 500 ms like Scratch, so 3D and pen projects no longer flicker; scripts started by a broadcast run in the same frame; faster Start on big projects; more extension compatibility; emojis in the interface replaced by icons.
  • Beta v15.50–15.61: Spark Studio and Song maker updates, costume and animation fixes, LAN sharing, the visitor counter, the Terms of Service, and many Scratch-compatibility fixes.
  • Beta v15.49.0: added Costumes / Tiles / Animation tabs; introduced tile-sprite mode for blank sprites; added a Glide action that creates eased in-between frames; grouped animation-generated costumes into folders; updated the Song maker with style-specific melodies and Chiptune, Rock, Trap and Cinematic styles; added three backdrops to Choose a Backdrop. Some tile-map persistence and per-sprite editor work remains unfinished.
  • Beta v15.48.0: rebuilt costume selection and transformation handles; shape-editing and conversion fixes; more Scratch-style behavior fixes and reported speed improvements on selected projects.
  • Beta v15.47.0: frame-by-frame costume animation with onion skin and playback; a rig-based Animation tab with bones; G-Spark walk/wave starter animations.
  • Beta v15.46.4: Power lines visualize broadcast-to-receiver and custom-block-to-definition links while a project runs.
  • Beta v15.46.3: Paint new creates a vector costume; vector Reshape and Eraser tools were enabled.
  • Beta v15.46.2: skip sound restarts that would be too brief to hear.
  • Beta v15.46.1: faster “item # of” lookup and a prompt-based “Open in G-Warp” Scratch project-ID link handler.
  • Beta v15.46.0: clone and runaway-script safety work, Stop responsiveness protections, recovery-related safeguards, text/list caps and a built-in report-a-bug entry.
  • Beta v15.45.0: optional Scratch-like visual mode and related editor polish.
  • Beta v15.31–v15.44: Bug Hunter, comments, right-click search/duplicate, costume menus, sprite/backdrop libraries, Stage selection and extension catalog improvements.

Performance numbers in team notes are reported results from specific projects and environments, not universal guarantees. See the current benchmark plan for how to compare builds.
