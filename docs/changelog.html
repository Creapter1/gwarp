Changelog

This is a short summary of release milestones recorded in the project's team log. It is not a complete list of every code change.

  • Beta v15.49.0: added Costumes / Tiles / Animation tabs; introduced tile-sprite mode for blank sprites; added a Glide action that creates eased in-between frames; grouped animation-generated costumes into folders; updated the Song maker with style-specific melodies and Chiptune, Rock, Trap and Cinematic styles; added three backdrops to Choose a Backdrop. Some tile-map persistence and per-sprite editor work remains unfinished.
  • Beta v15.48.0: rebuilt costume selection and transformation handles; shape-editing and conversion fixes; more Scratch-style behavior fixes and reported speed improvements on selected projects.
  • Beta v15.47.0: frame-by-frame costume animation with onion skin and playback; a rig-based Animation tab with bones; G-Spark walk/wave starter animations.
  • Beta v15.46.4: Power lines visualize broadcast-to-receiver and custom-block-to-definition links while a project runs.
  • Beta v15.46.3: Paint new creates a vector costume; vector Reshape and Eraser tools were enabled.
  • Beta v15.46.2: skip sound restarts that would be too brief to hear.
  • Beta v15.46.1: faster “item # of” lookup and a prompt-based “Open in G-Warp” Scratch project-ID link handler.
  • Beta v15.46.0: clone and runaway-script safety work, Stop responsiveness protections, recovery-related safeguards, text/list caps and a built-in report-a-bug entry.
  • Beta v15.45.0: optional Scratch-like visual mode and related editor polish.
  • Beta v15.31–v15.44: Bug Hunter, comments, right-click search/duplicate, costume menus, sprite/backdrop libraries, Stage selection and extension catalog improvements.

Performance numbers in team notes are reported results from specific projects and environments, not universal guarantees. See the current benchmark plan for how to compare builds.
