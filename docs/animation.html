Animation tools

Beta v15.49.0: Animation is now a real tab beside Costumes and Tiles in the costume section. Availability depends on the selected sprite; tile sprites do not show the Animation tab.

Costume folders

When you make costumes from an animation, frames use names such as walk//frame 1, walk//frame 2, and so on. The costume list groups matching names into a folder such as walk - 8 frames; open or close the group to view its frames. Renaming an animation updates the related costume names and animation block menus. Dragging costumes into or out of folders is not documented as supported yet.

Glide between poses

In the Animation editor, select Glide to create three eased in-between frames for each gap between key poses. The editor speeds up playback so the motion takes approximately the same time. Press Glide again to return to key frames. Choosing a custom number of steps or easing curve is future work, not a current documented control.

G-Warp has frame-by-frame and rig-based costume animation tools. Check the current app for the exact controls available to your selected costume.

Flipbook and onion skin

Flipbook-style frames help you draw motion one pose at a time. Onion skin shows nearby frames faintly as a drawing reference; it should not become part of the saved artwork. G-Warp intentionally uses its own colors and layer style.

Animation tab

  • Rig / bones: create bones and attach supported artwork.
  • Animate: pose frames and preview movement.
  • In-between / Smooth x2: create or smooth intermediate motion where supported.
  • Play: preview the animation.
  • Make costumes: turn animation frames into costumes when available.

Animation blocks

Animation blocks are G-Warp-specific. Test them in the target build and do not assume Scratch can import their behavior. Start with a short animation, preview it, then save before making larger edits.
