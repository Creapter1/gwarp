Coming from Scratch, TurboWarp or PenguinMod

G-Warp uses a familiar block-based workflow and aims to match standard Scratch behavior while keeping its own interface and adding G-Warp-specific tools.

What feels familiar

  • Snap-together scripts and block categories.
  • A Stage with sprites and backdrops.
  • Events, control flow, variables, lists, costumes and sounds.
  • Project import/export workflows for supported file types.

What looks different

  • Dark theme, violet accents and electric C-blocks.
  • G-Spark and G-Warp's own sprite/backdrop libraries.
  • Power lines, costume animation and Song maker tools.
  • The optional “Look like Scratch” setting is in More → Settings; it changes the interface style, not the underlying compatibility guarantees.

Project compatibility

Standard Scratch projects are the best candidates for interoperability, but full parity is not guaranteed. G-Warp-specific extensions, custom animation data and unsupported features may not transfer. Keep the original file, test the imported project, export a copy and reopen it in the target editor.

Some builds support opening a project from a Scratch project ID using a #scratch= link. Confirm the current published URL before sharing a link; the canonical website address is awaiting owner confirmation.
