Step-by-step tutorials

Make something small, test it, then build on it. These lessons use the block names listed for the current G-Warp workflow. If a block or control is missing in your build, stop and check the category/extension rather than guessing a replacement.

1. Make G-Spark walk

Create a few costume poses, preview them with Onion skin, and loop next costume with a short wait.

Open Tutorial 1 →

2. Make a clicker game

Create a Score variable, add points on sprite click, and play a sound.

Open Tutorial 2 →

3. Make a platformer jump

Use a gravity variable, a floor-color check and a Space-key event to build a starter jump.

Open Tutorial 3 →

4. Animate with bones

Rig a character, pose frames, preview the motion and turn frames into costumes.

Open Tutorial 4 →

5. Read Power lines

Connect a broadcast to its receiver and follow script connections with the debug overlay.

Open Tutorial 5 →

6. Make falling stars with clones

Spawn star copies, make them fall, then delete each clone when it leaves the Stage.

Open Tutorial 6 →

7. Build a quiz

Store questions and answers in lists, ask each question, and count correct answers.

Open Tutorial 7 →

8. Make a drawing app

Use the Pen extension and mouse sensing to draw on the Stage.

Open Tutorial 8 →

Tip: save a new copy before trying an unfamiliar block or an extension. G-Warp is beta and some features may change between builds.
