Keyboard shortcuts

Shortcuts may vary by browser, operating system and current editor focus. Use this as a quick reference and verify in the current beta.

  • Ctrl + O — open a project where supported.
  • Ctrl + Z — undo.
  • Ctrl + Y — redo where supported.
  • Ctrl + G — a G-Warp shortcut listed in the current task notes; verify its action in the app.
  • Arrow keys — move selected items or adjust a selection in supported tools.
  • Delete — remove a selected item where appropriate.
  • Space — used for playback in the Animation workspace when that workspace has focus.

Browser shortcuts can take priority. If a shortcut does not work, click the relevant workspace first and check the current controls.
