Block categories

Blocks are the pieces of code you snap together. The exact palette depends on the selected sprite and enabled extensions.

  • Motion: move, turn, point, glide and change position.
  • Looks: costumes, size, visibility, effects and speech/thought bubbles.
  • Sound: play sounds, stop sounds and change audio settings.
  • Events: start scripts from the green flag, key presses, clicks, broadcasts and other events.
  • Control: wait, repeat, forever, if/else, stop and clone-related flow.
  • Sensing: ask questions about keys, mouse, touching, time and other objects.
  • Operators: math, comparisons, logic, text and random values.
  • Variables: store values that scripts can read or change.
  • Lists: keep ordered collections of values.
  • My Blocks: create custom blocks with inputs; procedure parity is an active compatibility priority.
  • Animation / GWrap AI: G-Warp-specific features; do not assume these export to Scratch.

Editing scripts

Drag blocks from the palette and snap them together. Right-click in the code area for available actions such as block search, duplicate and comments. Comments help people understand a script; they do not run as code. If a block behaves differently from Scratch, record the smallest project that reproduces it.

Bug Hunter

The project’s release notes describe Bug Hunter as an achievement for finding bugs. It is a bug-finding challenge, not a guarantee that the app has been fully tested. When you find a problem, write down the steps, expected result and actual result before reporting it.

Power lines

When enabled in More → Settings, Power lines draw a visual connection from a broadcast block to matching “when I receive” scripts, and from a custom-block definition to its uses. They are a debugging aid drawn over the workspace, not extra code. Turn them off in Settings if the lines distract you.
