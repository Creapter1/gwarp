Safety and privacy

Last updated: 21 November 2026

G-Warp is a beta project. This page describes its main data paths in plain language. A specific build, extension or outside service can behave differently, so review permissions and project contents before using or sharing them.

What stays on your device

  • The editor does not require an account. Project files and browser-stored project data stay on your device unless you choose a feature that sends them somewhere.
  • Clearing browser storage, using private browsing or cleaning your device can erase projects that were not exported. Keep a separate backup.
  • Desktop diagnostic reports are created on your device. Review them before sharing; they can include project details or a record of actions needed to reproduce a bug.

Website visitor counter

The public G-Warp website uses a counter to show total visits, browser counts and the number of tabs recently online. It sends count updates to a Firebase Realtime Database. A marker in local storage helps count a browser once, and a random temporary session code is used for the online count. The public dashboard shows totals rather than names or exact locations; the counter is not used for advertising or cross-site profiling.

Firebase and the network providers that carry requests may process technical request data, such as an IP address, under their own policies. G-Warp does not use the counter to identify individual visitors. Read Firebase privacy information and the Terms of Service. GitHub Pages or another host may also process technical data under its own policy.

Retention and visitor choices

Each counted G-Warp website or editor page open increments an aggregate visit total. A local-storage marker helps count the same browser once; it stays until that browser's site data is cleared, and clearing it may cause that browser to be counted again. The current G-Warp code does not automatically expire aggregate totals stored in Firebase; they remain until the project owner resets or deletes them. Online status uses a random temporary session code. The page attempts to delete it when the tab closes, and the public stats dashboard removes stale entries when they are more than ten minutes old. Requests can fail if a browser or network blocks Firebase, in which case the counter will not update. Firebase may separately retain technical request logs under its own policies.

Online features and third parties

  • Online AI: prompts, selected code and files you send to a connected provider leave your device and are handled under that provider's terms and privacy policy. Do not send secrets or information you are not allowed to share.
  • Cloud variables: project values are sent to the selected cloud service and may be visible to other players using that project. Never store personal details, passwords or private data there.
  • Extensions: extensions can communicate with outside services or access project data. Safety labels and prompts are aids, not guarantees. Read each warning and use only code you trust.
  • LAN sharing: the selected project is sent to devices that join your local session. Share only with people and networks you trust.
  • GitHub issues: reports you submit may be public and GitHub receives their contents. Remove personal details and inspect attachments first.

Before sharing a project

Remove names, addresses, school details, passwords, API keys, private URLs and anything you do not want published. Check every asset and extension for its license. If a bug report needs a project, make a minimal copy and inspect it first.

Children

Parents and guardians should help children review online features, extensions and outside AI services. The age and consent rules of an outside service may differ from G-Warp's. Do not submit a child's personal information in a public report.

Security concerns

For a security concern, report the file or feature without posting a secret value. See the Terms of Service for copyright reports and contact options.
