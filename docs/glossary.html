G-Warp glossary

Short explanations of words you may see while making games, drawing costumes, animating characters, and sharing projects. Some controls and labels can vary by build or enabled extension.

Safety labels and compatibility notes describe the project's current documentation, not a guarantee that every extension or imported project is safe or identical across apps.

A–C

Animation
A sequence of poses or images that creates the feeling of movement.
Answer
The text a player types after an ask and wait question.
Backdrop
The background picture used by the Stage.
Bitmap
Artwork stored as pixels, like a photo or pixel-art image.
Block
A puzzle-shaped coding command or value.
Boolean
A value that is either true or false; it fits a hexagon-shaped input.
Bone
A controllable joint/segment used to pose artwork in the Animation tab.
Broadcast
A message one script sends so matching event scripts can start.
C-block
A block shaped like a C that holds other blocks inside it, such as repeat.
Clone
A temporary copy of a sprite created while the project runs.
Compatibility
How well a project behaves when opened in another app or version.
Condition
A test that decides whether a script should do something.
Costume
One look or pose belonging to a sprite.
Coordinate
A position described by numbers, often x (horizontal) and y (vertical).

D–L

Event
Something that triggers a script, such as clicking the Green Flag or pressing a key.
Extension
An add-on that provides extra blocks or tools.
FPS
Frames per second; how many animation frames are shown each second.
Frame
One still pose or image in an animation.
Green Flag
The start control that runs scripts waiting for the flag event.
Hat block
A block at the top of a script that starts it when an event happens.
Input
A slot or value used by a block, such as a number or a dropdown choice.
List
An ordered set of items, like names or scores.
Loop
A control structure that repeats blocks.
Message
The named signal sent by a broadcast.
Modulo (mod)
An operator that calculates a remainder according to its math rule.
Monitor
A value display shown on the Stage, such as a variable or list.
Onion skin
A faint view of nearby animation poses used as a drawing guide.
Operator
A block that calculates, compares values, joins text, or uses logic.
Parent / child
In a bone rig, a child bone follows its parent bone's movement.
Reporter
A rounded block that reports a value, such as a number, text, or position.
Repeat
A loop that runs its inner blocks a chosen number of times.
Rotation centre
The point around which a costume or sprite rotates.
Rig
A set of bones and attached artwork used to pose a character.
Script
Blocks connected together to describe actions.
Sprite
A character or object in the project that can have code, costumes, and sounds.
Stage
The area where the project runs and sprites appear.
Stack
A connected vertical sequence of blocks.
Variable
A named place to store a value, such as a score.

M–Z

Vector
Artwork made from editable paths and shapes rather than only pixels.
Bitmap Select
A tool that selects a region of pixels in bitmap artwork.
Bounding box
A rectangle around selected artwork with handles for changing size or rotation.
Clone limit
A safety cap on the number of sprite copies a project can create.
Dangerous label
A warning category for an extension that may access sensitive information or powerful capabilities.
Export
Save a copy of a project or asset into a file format.
Forever
A loop that keeps repeating until the script is stopped.
In-between
A tool that creates poses between two animation poses.
Join
An operator that sticks two pieces of text together; it does not automatically add spaces.
Random
A choice selected by chance from the available range or options.
Restore point
A saved recovery copy that can help recover an earlier project state.
Safe label
An extension catalogue label meaning no sensitive-access flag was identified; it is not a guarantee of no bugs or risk.
Smooth x2
An animation tool that adds/smooths intermediate motion in the rig workspace.
Moderate label
An extension catalogue label noting extra capabilities or risks that deserve attention.
.pmp
A PenguinMod project file extension; the exact container/data variant matters for compatibility.
.sb3
A Scratch 3 project file, usually a ZIP archive containing project data and assets.
SVG
A text-based vector image format used for scalable shapes.
PNG
An image file format that stores pixels and can support transparency.
Beta
A release that is still being developed and may contain bugs or unfinished behavior.
Browser permission
A permission a browser asks for before a page can use certain device or site capabilities.
Palette
The list of available blocks or tools in the current category.
Pose
A particular arrangement of a rig or character in one animation frame.
Text-to-speech
A feature that turns text into spoken audio, usually through an extension or service.
Under-13 rule
The project's guideline that children under 13 need a parent's or guardian's help/OK before sending personal information online.
Web loader
A feature that fetches a project from a web link or project ID when supported.
Variable scope
Which sprites or parts of a project can read or change a variable.
Wait block
A control block that pauses its script for a specified amount of time.
