Costume editor

Use the costume editor to draw or change a sprite. Beta v15.48.0 includes a Select tool with resize handles and rotation, according to the release log; test your own workflow and save a backup.

Paint new and drawing fit

The release notes say Paint new was corrected to open a vector costume with a drawing area fitted to the Stage dimensions, and that the drawing should fit its canvas. Save a copy before converting a costume; if the artwork shifts, clips or changes size, record the exact steps and report it rather than assuming the import or conversion succeeded.

  • Select: click an object to select it; use handles to resize and the rotation handle to rotate.
  • Shift and keyboard: some modifier/arrow-key behaviors may depend on the active tool; verify them in the current build.
  • Group / Ungroup: organize multiple selected objects when the controls are available.
  • Flip: mirror selected artwork.
  • Reshape: adjust supported vector shapes.
  • Brush / Eraser / Fill: draw, erase or fill artwork.
  • Text: add text; double-click existing text to edit where supported.
  • Rectangle / Circle / Line: draw geometric shapes.
  • Vector / Bitmap: vector art uses shapes; bitmap art uses pixels. Convert only after saving a backup.
  • Rotation centre and zoom: use the editor controls to set how the costume rotates and inspect details.
  • Undo: reverse recent edits when possible.

Report any jumping, lost handles, clipped drawings or unexpected conversion changes with exact steps. Some advanced bitmap-selection and high-resolution workflows may still need verification.
