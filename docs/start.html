Your first project

G-Warp uses snap-together blocks to make games, animations and interactive stories. This guide describes the basic flow; exact labels can change during beta updates.

  1. Open G-Warp and create a project.
  2. Select a sprite, then choose the Events category.
  3. Drag a start/green-flag hat into the code area.
  4. Add a Motion block such as “move” or “change x”.
  5. Press Start in the top bar and test it on the Stage.
  6. Use Pause to pause and Stop to stop running scripts.
  7. Use More → Save to your computer to keep a local copy.

Stage and backdrops

The Stage is the scene behind your sprites. Select the Stage thumbnail near the sprite list, then open Backdrops to choose or edit the background. Select a sprite again when you want to return to that sprite’s scripts or costumes. The Stage stays in place while its backdrop changes.

Open a project

Use Use your project or the project-open control to select a supported file. Keep your original copy before importing/exporting. Support for advanced extensions and nonstandard data varies.

Remember

G-Warp is beta software. Save often, and check an exported project in its target editor before relying on it.
