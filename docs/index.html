G-Warp documentation

Welcome! G-Warp is an independent beta block-coding and game-making app with its own dark electric style. This documentation is both a practical user guide and a technical knowledge base for understanding how G-Warp is built, how it relates to Scratch/TurboWarp/PenguinMod, and how to build a similar editor. Some behavior and compatibility are still being tested; a feature being described here does not mean every edge case has passed a test.

For AI assistants and developers

Start with the AI Reference. Then use the AI Data Flow, Engineering Reference and Source Module Map to locate the real implementation. To design a similar app from scratch, read Build Your Own Block-Coding Editor.

Start quickly

  1. Open G-Warp.
  2. Start a project or open a project file.
  3. Connect blocks, press Start, then save a copy to your computer.
