Block-based programming and editor architecture

These guides explain how visual programming editors work, how Scratch's workspace and virtual machine fit together, how related projects approach execution and compatibility, and how to design a block-coding editor of your own. You do not need to know G-Warp to use the general learning material.

Start with the concepts

  • How Block-Based Programming Editors Work — learn about blocks, connections, project models, runtimes, rendering and project files.
  • Scratch VM Explained — follow the path from a visual block to a running script.
  • Scratch, TurboWarp, PenguinMod and Independent Editors — understand different approaches without assuming they share the same code.
  • Build Your Own Scratch-Style Block-Coding Editor — a practical, staged implementation guide.

Explore G-Warp

G-Warp is an independent beta block-coding and creative app. Its own implementation uses a custom workspace, runtime, Stage renderer, media tools and project handling. It is one example of an independent editor, not a replacement for the upstream technical references.

Use the Engineering Reference and Source Module Map for source-specific details. Feature guides describe the user-facing editor and identify areas where testing is still incomplete.
