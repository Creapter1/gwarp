Troubleshooting

Project seems stuck

If the app offers a “Keep going / Stop” choice, use Stop if you need to interrupt a runaway script. Save a copy before restarting when possible.

Too many clones

G-Warp has a default clone limit of 300 and a higher safety ceiling for the Infinite Clones option, according to the current release notes. Large clone counts can still slow down a project. Delete clones when they are no longer needed.

Slow project

  • Try the same project with fewer clones and effects.
  • Check whether many scripts run every frame or loop without waiting.
  • Separate script-heavy and graphics-heavy causes before changing code.
  • Use the same browser, project and settings when comparing results.

Extension blocked

Read its safety label and warning. Some extensions may be intentionally unavailable or may not work in every environment.

Report a bug

Use the built-in report flow or the project's GitHub issue link. Include steps, expected and actual results, browser and build version. Remove personal information and inspect attachments before sending them.
