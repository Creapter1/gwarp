!! G-WARP IS NOT SCRATCH-VM !!
G-Warp has its OWN engine. There is NO window.vm, NO runtime.sequencer,
NO scratch-render. Code that uses window.vm / runtime / sequencer /
renderer DOES NOTHING in G-Warp. Learn ideas from Scratch/TurboWarp,
but write code against the names below.

MAIN OBJECT: window.Engine
  Engine.sprites            array of sprites (clones have isClone = true)
  Engine.activeSpriteIndex  the sprite selected in the editor
  Engine.threads            running scripts (ScriptThread objects)
  Engine.variables / Engine.lists / Engine.variableVisible / listVisible
  Engine.backdrops / Engine.activeBackdrop
  Engine.isRunning / Engine.isPaused / Engine.isTurbo
  Engine.cloneLimit         clone cap (default 300 already exists)
  Engine.actualFps / Engine.lastFrameTime
  Engine.mouse / Engine.keysPressed / Engine.answer / Engine.audioCtx
  Engine.broadcasts / Engine.extensions / Engine.tilemap / Engine.behaviorSystem

OTHER GLOBALS YOU MAY USE
  window.GW                 general helpers
  window.GW8                undo/redo history (pushHistory, scheduleHistory)
  window.GW_DIALOG(...)     G-Warp's dark dialog  -> use this, never alert()
  window.GW_CONFIRM / GW_ASK  dark confirm / ask boxes
  window.GW_FEATURE_OFF(key) true if a feature is switched off
  window.GW_WARP_GUARD      existing stuck-script / warp protection
  window.GW_SETTINGS        settings
  window.GW_BUILD           version info
  window.GW_EXT_DANGER      extension danger levels
  window.GW_SCRATCH_LOOK    the optional "Look like Scratch" switch

REAL HOOKS FOR SPEED WORK (checked in app.html - use THESE names)
  Collision:  GW.spritesTouch(a, b)      <- "touching sprite" check
              (there is NO Engine.touching / checkTouching / touchingSprite)
  Threads:    class ScriptThread, each has a  step()  method;
              the main loop walks Engine.threads. (NO Engine.stepThread /
              tickThread / updateThread. The "stepThreads" in app.html is
              only a fake stub for extensions - don't wrap it.)
              ScriptThread fields: sprite, blocks (the WHOLE script, never
              empty), pc (which block is next), callStack, waitUntil
              (time it's waiting until), finished. ScriptThread is NOT on
              window; reach it via Engine.threads[i].constructor.
              Idle check = finished === true or performance.now() < waitUntil.
              Sprites use  visible  (true/false).
  Pen:        pen canvas comes from a private function ensurePenCanvas();
              there is NO Engine.pen / penDraw / drawPen. Pen code needs
              Claude to expose a hook first -> write "UNSURE: need pen hook".
  Renderer:   G-Warp draws with its own 2D canvas code. NO Engine.renderer,
              NO WebGL drawables, NO isTouchingDrawables.
  Projects:   G-Warp ALREADY opens .sb3 and ZIP-type .pmp files (More ->
              Load from your computer, accepts .sb3 .pmp .zip .json) and
              has fromPenguinMod(id) for PenguinMod links. Only the newer
              PROTOBUF .pmp files are missing.

IF YOU NEED SOMETHING NOT ON THIS LIST
  Don't invent it. Write "UNSURE: need access to <thing>" in your NOTES
  and Claude will wire it up. Guessing names = code that silently fails.

HOW A MODULE MUST LOOK
  (() => {
    'use strict';
    if (window.GW_MYFEATURE) return;                    // safe if loaded twice
    if (window.GW_FEATURE_OFF?.('myFeature')) return;   // switch-off key
    const E = () => window.Engine;                      // read Engine lazily
    ...
    window.GW_MYFEATURE = { ... };                      // what others can call
  })();
