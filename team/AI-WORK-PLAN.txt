ROADMAP — ORDERED BY RISK AND DEPENDENCIES

P0 — BASELINE, FREEZE / STOP RELIABILITY
Claude verifies active model and owner authorization, records actual main/working-branch commit and app.html/index.html hashes, then reproduces the reported freeze/slow Stop symptom in a safe test copy. The 81,000-clone / approximately 45-second report is owner-reported, not independently reproduced. Record baseline clone count, freeze timing, Stop latency, FPS and recovery. Inspect the existing clone limit before adding another limiter. Test clone boundaries 299/300/301, rapid creation, Stop during load, clone hats, broadcasts, Pause/Stop, turbo, reload/duplicate load, large text/lists, feature-off, and ordinary scripts. Compare chatgpt/clone-safety.js and deepseek collision/clone reports against the real current source. Do not bundle unrelated fixes.

P1 — COSTUME EDITOR
First verify the actual editor root, state fields, canvas ownership, SVG attributes, coordinate conversion, history/undo APIs and listener scope. DeepSeek's select-C, fill-C, text-B, eraser-C and undo-C are candidates, not integrated fixes. Use a disconnected harness with stage canvas plus bitmap/vector costume canvases; test zoom/pan, pointer cancel/lost capture, multi-object selection, resize, rotation center, undo/redo, sprite/costume switch, repeated load, feature-off and save/reopen. No tool may alter a non-costume canvas.

P2 — PROJECT FILES / OPEN-IN-G-WARP
Preserve existing .sb3 and ZIP-based .pmp support. The newer protobuf .pmp path needs the confirmed parser API, a real legal fixture, asset fidelity and malformed/oversized-file tests. Test load/save/reload and safe failure. For chatgpt/scratch-link.js and Gemini's extension, test valid/invalid IDs, user consent and cancel, network/load failures, hash clearing, popup, Scratch SPA navigation, repeat injection, permissions, packaging and target URL. Do not assume the old GitHub Pages URL changed until the owner confirms the canonical destination.

P3 — SCRATCH BEHAVIOR / REGRESSION TESTS
Grok's specs and 75 written cases are a reference/test backlog, not a passing automated suite. Label each expected result as source-confirmed, directly tested, inferred or unresolved. Prioritize negative modulo/rounding, text-number comparison, case behavior, list index 0, clone limits, hats/broadcast order, pen hue wrap, procedures and project round-trip. Convert a small verified subset to deterministic executable fixtures where practical; record expected/actual, browser/version, date and evidence.

P4 — EXTENSIONS / SAFETY
Grok's static gallery audit is delivered at grok/EXTENSIONS-check.txt. Still verify published-site loading and actual behavior, permission/data access, Dangerous warnings, failure isolation and credits/licences; static URL resolution alone is not end-to-end acceptance. Review Gemini packaging, required PNGs, permissions, Chromium/Firefox behavior, storage failures and end-to-end project opening. Static URL inspection is not a load test.

P5 — ORIGINAL VISUAL ASSETS
Gemini prepares original, distinct SVG options for the extension icon, favicon, block categories, achievement badges, G-Spark poses and hero art. Owner selects before integration. Keep G-Warp's electric dark/violet/green style, no Scratch art/logos/cat, no scripts or external assets in SVG, and verify legibility at target sizes.

LATER / OWNER-PRIORITIZED
GWrap AI, defined 60-FPS benchmarking, Song Maker redesign, extra developer/education features and domain work remain backlog unless the owner reprioritizes. Do not create activity merely to fill time.

DONE MEANS
A task is only complete for its declared scope when the changed files, baseline, exact checks, actual results, untested areas, risks and next step are recorded. Keep the report concise; link detailed evidence rather than copying it into several files. Update the queue/merge state truthfully and checkpoint before switching tasks or ending a long session.
