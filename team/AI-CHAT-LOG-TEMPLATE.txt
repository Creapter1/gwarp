G-WARP — AI CHAT LOG TEMPLATE
Purpose: durable, truthful context when chat history is truncated, deleted, or unavailable.

RULES
- Store this file as <your-ai-folder>/AI-CHAT-LOG.txt. Append entries; do not overwrite earlier history.
- Keep the user's request separate from the AI's response/interpretation.
- Quote the request accurately where available. If unavailable, write ORIGINAL CHAT NOT AVAILABLE; do not reconstruct it as a quote.
- Never record passwords, API keys, access tokens, private keys, or unrelated sensitive personal data. Redact secrets and say [REDACTED — SECRET OMITTED].
- Mark evidence honestly: SOURCE-VERIFIED, STATIC-ANALYSIS, BROWSER-VERIFIED, NOT-TESTED, or other clearly explained status.
