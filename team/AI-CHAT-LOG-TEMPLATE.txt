G-WARP — MANDATORY AI CHAT LOG TEMPLATE
Purpose: prevent context loss, false assumptions, duplicated work, and unsafe/incomplete handoffs.

ZERO-EXCEPTION RULE
- Every AI/agent/model working on G-Warp must keep this file at <ai-folder>/AI-CHAT-LOG.txt. No exceptions for short sessions, reviews, failed attempts, temporary agents, or sessions with no file changes.
- Read AI-TEAM.txt, this template, and your own existing log BEFORE any work. If the log does not exist, create it from this template before proceeding.
- Append a session-start entry before work; append progress at meaningful milestones; append closeout before stopping, switching context/model, handing off, or claiming completion.
- If you cannot update and verify your own log, HARD STOP all project work and notify the owner. Do not continue unlogged.
- A task is NOT DONE until its personal log closeout is committed AND read back from GitHub. The shared AI-TEAM work log is also required and does not replace this file.
- New timestamps must be UTC ISO-8601 with seconds and Z (example: 2026-10-24T15:15:03Z). Never guess or backdate. If unavailable, say TIME NOT AVAILABLE. Optional local time must include an IANA timezone.
- Never alter historical timestamps, invent missing conversation text, claim unrun tests, or mark partial work DONE. Label reconstructed summaries and cite their supporting repo evidence.
- Append only. Never overwrite or delete prior entries. Never edit another AI's personal log. Redact secrets.
