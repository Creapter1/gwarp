WHAT GWRAP AI IS TODAY
GWrap AI is the helper in the block palette (the "GWrap AI" category). A kid types what they want ("make it jump").
It works OFFLINE: it matches the words to a list of RECIPES (they BUILD real scripts in the code area when the kid
presses "Add these blocks") and TIPS (short answers with an optional button). Today there are only 13 recipes and
6 tips (ids: arrows, jump, bounce, animate, hello, score, music, follow, spin, edge, grow, ghost, teleport;
tip-if, tip-draw, tip-record, tip-song, tip-save, tip-undo). Your job: make it know 300+ things.

RECIPE (builds a working script)
{
  "id": "r-walk-animate-arrows",          // unique, starts with r-
  "emoji": "🚶",
  "title": "Walk with the arrow keys and animate",
  "keys": ["walk","animate","arrow","arrows","costume","move"],   // single words, lower case
  "q": ["make my character walk with arrows and change costumes", "walking animation when i press right",
        "how do i make him move and animate at the same time"],
  "steps": ["When the green flag is clicked, keep checking forever.",
            "If the right arrow is pressed: face right, move 5 steps, show the next costume.",
            "Same for the left arrow. Add more costumes for a smoother walk."],
  "prep": { "vars": ["score"], "lists": [], "messages": ["game over"] },   // optional: things to create first
  "script": [ STACK, STACK, ... ]          // one or more scripts
}
STACK = [ BLOCK, BLOCK, ... ]   (the first block is normally a hat: when_flag, when_key, when_clicked, when_broadcast,
                                 when_clone, when_backdrop)
BLOCK = [ "type", [inputs...], [menus...], { "body": STACK, "else": STACK, "cond": NODE } ]
        - inputs: the typed values in order, as strings: ["10"], ["Hello!","2"]
        - menus: the dropdown values in order: ["right arrow"], ["mouse-pointer"], ["score"]
        - an input can be a nested round block instead of a string: {"r": ["op_random", ["-200","200"]]}
        - the 4th part is only for C-blocks: repeat / forever / if / if_else / repeat_until (body, else, cond)
          and for wait_until (cond).
NODE (the pointy condition in if / wait until / repeat until):
  {"type":"key_pressed","key":"space"}           {"type":"touching_edge"}
  {"type":"touching_pointer"}                      {"type":"touching_sprite","target":"OTHER_SPRITE"}
  {"type":"mouse_down"}
  {"type":"op_gt","args":[A,B]}   {"type":"op_eq","args":[A,B]}   (for "less than" swap A and B in op_gt)
  {"type":"op_and","args":[C1,C2]} {"type":"op_or","args":[C1,C2]} {"type":"op_not","args":[C]}
  A/B values: {"type":"literal","value":"10"} {"type":"get_var","name":"score"} {"type":"x_position"}
              {"type":"y_position"} {"type":"timer"} {"type":"answer"} {"type":"mouse_x"} {"type":"mouse_y"}
              {"type":"costume_number"} {"type":"size_reporter"}
              {"type":"op_random","args":[{"type":"literal","value":"1"},{"type":"literal","value":"10"}]}
  Use "OTHER_SPRITE" when the recipe needs another sprite; Claude's loader puts in the real name.
