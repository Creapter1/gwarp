A. BROKEN (G-Warp has it, but it does the wrong thing) - Claude
[x] A1  A new block jumped to another sprite when you clicked / added / duplicated a sprite.
        Fixed in v15.49.1 (new scripts belong to their sprite at once). Same cause: "Delete N Blocks" counted wrong.
[ ] A2  Variable and list monitors are switched on but hidden UNDER the stage picture (score is invisible).
[ ] A3  Undo does nothing after dragging in a new block. Ctrl+Shift+Z undoes again instead of redo.
[ ] A4  Clicking a script or a palette block does not run it (no glow, click again to stop).
[ ] A5  Right-clicking a reporter inside a block acts on the OUTER block (Delete removes the whole "move" block,
        Duplicate copies the whole script).
[ ] A6  "when this sprite clicked" only works while the project is running (Scratch: also when stopped).
[ ] A7  Block right-click menu: runs off the bottom of the window, Escape doesn't close it, can be open at the same
        time as the empty-area menu, Duplicate also copies the blocks ABOVE and doesn't stick to the mouse.
[ ] A8  Right-clicking a comment opens the wrong menu.
[ ] A9  The Delete key does nothing on a clicked block.
[ ] A10 Number inputs accept letters ("abc" in "move ( ) steps").
