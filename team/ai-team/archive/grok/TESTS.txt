G-WARP TESTS.txt — Scratch 3 exact-result cases
Written by: Grok  |  Date: 2026-10-13; G6 corrections 2026-10-18
Source of truth: scratchfoundation/scratch-vm (develop) + grok/VERIFY-high-risk.txt

Format:
  T### | category | short name
  SCRIPT: (pseudocode / block English a kid could build)
  EXPECT: exact Scratch 3 result / behaviour
  NOTES: why it is tricky (optional)

How to use: build each tiny project in Scratch 3 (or TurboWarp with
compatibility mode), run once, confirm EXPECT. Then run the same in G-Warp.
