# Tab Plus (＋) — owner's idea, 2026-10-26

**Status: IDEA ONLY.** Nothing is built yet. The owner said: "for now, add that as an idea." Written down by Claude.

## The idea (owner's words, short)

Next to the main tabs (**Code · Costumes · Sounds**) there is one more tab: **＋** ("Tab Plus").
With it, creators can **add their own extra tabs** to a project.
This becomes **G-Warp's own new way to extend the app**, next to the extensions we already have. Only G-Warp has it.

## What it could look like (first thoughts, for the owner to change)

1. Click **＋** → a small menu: *"Add a tab"*. You pick a kind of tab and give it a name and an emoji.
2. The new tab sits after Sounds, like the others. Right-click → rename, move, remove.
3. The tab is **saved inside the project**, so whoever opens the project sees it too.

Kinds of tabs we could start with (owner picks which):

| Tab kind | What it does | Uses what we already have |
|---|---|---|
| 📝 Notes | A page of notes / instructions / to-do for the project | — |
| 🗺️ Tilemap | Draw levels with tiles (the TODO already wants Tilemap to move out of Code — this is a home for it) | the Tilemap tool |
| 🎼 Music | Song maker + Create Melody as a full tab of its own | Song maker, Create Melody |
| 🎬 Animation | Flipbook / bones animation with more room | Flipbook, Animation blocks |
| 📊 Variables | A big table of all variables and lists, editable | the variable monitors |
| 🧩 Extension tab | An extension can bring its own tab (its own editor, its own help page) | the extension system |

## Rules it must keep (from TODO.txt + owner)

- **Projects still open in Scratch / TurboWarp.** Extra tabs are saved as extra data that Scratch simply ignores
  (like comments and G-Warp's other extras). Nothing in the blocks changes.
- **Safe for kids:** an extension tab never runs JavaScript blocks and never sends data without a parent's OK (under 13).
  Dangerous extension tabs are marked, like dangerous extensions are now.
- **G-Warp's own look**, not Scratch's. Additive: the three normal tabs never change.
