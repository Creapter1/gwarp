EXECUTIVE SUMMARY
1. The repository contains substantial useful work, but the merge queue overstates readiness in several places. PICK is not equivalent to safe-to-integrate.
2. Highest-risk issue: DeepSeek costume proposals assume CE.state.mode, generic canvas selectors, and data-gw-shape attributes despite ENGINE-MAP documenting CE.state.costumeMode and saying several editor selectors/attributes are UNSURE. Multiple modules attach global document listeners and can intercept unrelated canvas interactions. Do NOT integrate the five costume candidates yet.
3. ChatGPT clone-safety is a meaningful candidate but overrides clone creation/deletion/Stop behavior and has not been browser-tested. It must be diffed against the current engine and tested for side effects before selection.
4. ChatGPT scratch-link is small and has a clear user-consent step, but it depends on a live GW_WEB.load hook and has not been integrated or tested end-to-end. The Gemini extension's hash link therefore also depends on that app handler existing in the published build.
5. DeepSeek protobuf .pmp loader is explicitly incomplete: it treats every non-ZIP buffer as protobuf, relies on a CDN import path/API that is marked UNSURE, returns an empty asset map, and has no real project fixture. Its current test only checks fake byte sequences and error handling; it is not a meaningful compatibility test.
6. Grok has useful broad behavior specifications and 75 written cases, but several edge expectations are explicitly uncertain or potentially contradictory. These are a specification/test backlog, not a passing test suite. G5 extension audit remains open.
7. Gemini's extension has a coherent draft flow, but icon PNG paths referenced by manifests are not present in the current tree (only gspark.svg and make-icons.js are present); packaging requires generating/committing icons. The SVG is documented as a placeholder, and real cross-browser/end-to-end tests are missing. Firefox API namespace compatibility and SPA navigation behavior need explicit testing.
8. ChatGPT UI-AUDIT and Claude's docs/LIVE-UI-VERIFICATION must be reconciled: the latter records 10 PASS results for a narrow scope and explicitly corrects the single-click category finding. Do not claim broader UI/engine correctness.
9. No current repository evidence proves any candidate was integrated into app.html. The current app blob ID should be recorded before future edits and checked afterward.
