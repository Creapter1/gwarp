1. METHOD
---------
- "Top 20" = official Scratch built-ins people still load in TW + first-party
  TurboWarp gallery entries that appear first in extensions.json / are
  commonly cited (Files, Gamepad, Box2D, Fetch, Runtime Options, Pen+,
  CloudLink, Local Storage, Utilities, Stretch, Cursor, Pointerlock, etc.).
- G-Warp support = opcode strings or gallery card present in app.html
  (static). NOT a live load test of each .js.

Support key:
  FULL   = core path / opcodes present for typical blocks
  LOAD   = in gw10GalleryData (can load as external ext); runtime untested
  PARTIAL= some related code, incomplete parity
  NONE   = no meaningful support found
  DANGER = in GW_EXT_DANGER.LIST (personal data warning)

3. NOTES PER GROUP
---------------------------------------------------------------------
A. Scratch official extensions
   Pen/Music are expected in any Scratch-compatible player. G-Warp has
   opcode identifiers in source; full stamp/layer/pen color parity needs
   fixture runs (see DeepSeek speed-pen notes if present).

B. TurboWarp gallery (unsandboxed)
   All listed gallery IDs appear in G-Warp's embedded gw10GalleryData
   (184 cards). Loading = user adds extension URL; execution depends on
   unsandboxed bridge (GW_EXT_*). Safety: CloudLink + Clipboard are on
   Dangerous LIST (EXTENSIONS-check.txt).

C. Runtime Options
   Blocks that set FPS / interpolation / clone limit / fencing map to
   TurboWarp runtimeOptions (see SPEC-turbowarp-runtime.txt). G-Warp
   should either implement equivalent flags or no-op with a clear message.

D. Network extensions (fetch, cloudlink, http)
   Require host permissions / CORS; mark MODERATE or DANGER as already done.
