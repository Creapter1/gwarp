HIGH-PRIORITY FINDING: USER-SUPPLIED AI KEY
app.html includes a user-supplied Anthropic API-key feature. The key is stored in sessionStorage by default; if the user checks “Remember the key on this computer,” it is saved in localStorage. Browser code sends the key directly to api.anthropic.com. No hard-coded key was found, but localStorage is not a secure vault: scripts running on the same origin may be able to read it. A public browser app cannot hide a shared provider key from its users or guarantee that a key is impossible to steal.

The request also sends project-derived context: sprite names, selected sprite name, variable names, and selected-sprite script/block text, in addition to the user's question. The current visible copy does not clearly preview all context being sent.

REQUIRED RULE FOR ALL AI CONTRIBUTORS
- Never place real API keys, tokens, passwords, private keys, cookies, or other credentials in source, examples, screenshots, reports, test fixtures, commits, issues, prompts, or handoffs. Use dummy placeholders only.
- Never ask the owner to paste a live key into chat.
- Never put a shared provider key in app.html, index.html, an extension, or any public browser bundle.
- User-owned key flows must clearly identify the provider, request destination, possible costs, project context transmitted, storage choice, and how to remove the key. Session-only storage should be the default. Persistent browser storage must be an explicit opt-in with a warning that it is not a secure vault.
- Never include keys in exports, project files, autosaves, diagnostics, crash reports, AI reports, logs, or extension messages.
- If a real key may have been exposed, do not copy it into a report. Tell the owner the file/path and line, revoke or rotate it, and assess current source plus history. Deleting a line does not invalidate a leaked key.
- If a shared AI service is ever needed, prefer a trusted server-side proxy with access controls, rate limits, and server-side secret storage. Do not create or deploy a backend without owner approval.
