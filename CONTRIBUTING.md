# Contributing to G-Warp

Thank you for helping! G-Warp is a free, fan-made project.

- **License:** by sending code, art, sounds or text to this repository, you agree that it is shared under the same **MIT License** as G-Warp (see `LICENSE`), and that it is your own work or you have the right to share it.
- **Other people's work:** do not add code, pictures, fonts or sounds made by someone else unless their license allows it. Say where it came from and what license it has, so it can be added to `THIRD-PARTY-NOTICES.md`.
- **No Scratch art:** G-Warp keeps its own look. Please do not add Scratch's cat, logos or art.
- **Kids use G-Warp:** keep everything friendly and safe for ages 10-15. Never add code that collects personal data.
- **Bugs:** please report them with the steps, what you expected and what happened.
