Block coding,
with electricity.

G-Warp is a block-based game maker with a dark, electric look, a mascot named G-Spark, a song maker and an extension library with safety labels. It aims to match the familiar workflow of Scratch, TurboWarp and PenguinMod, while compatibility is still being improved and should be checked project by project.

How a project flows

Make G-Spark move in 3 blocks

Drag blocks from the palette and snap them together. Here's a whole first project, made from scratch in a new file.

1Start with an event

Drop when flag clicked into the code area. Events have black text, so they're easy to read.

2Add a loop

Snap forever underneath. Anything inside it keeps repeating.

3Put motion inside

Add move 10 steps and turn 15 degrees. G-Warp's C-blocks show a live electric wire on the inside.

Then press Start

G-Spark spins around the stage

Start, Pause and Stop sit in the top bar. Change the numbers while it runs and see the result straight away.

Music

A song maker built in

Pick a genre, a mood and a theme, then press Generate. G-Warp writes a whole backing track for your game: melody, backing, bass and drums, laid out in parts you can switch on and off.

  • Genres and moods like Trap, Dark and Gaming. Mix up to 3 of each.
  • Energy for every part: calm, happy, wild or fire. Click to change it.
  • Key, speed and length, from short loops to full songs.
  • Loop maker, instruments and a sound editor in the same Sounds tab.

Quick answers

Is G-Warp free?

The beta is available to try. Check the repository for current licence details.

Does it work offline?

The app is a local HTML file, but some features or external resources may need an internet connection. Test your setup before going offline.

Will my Scratch project open?

Many standard projects are the best candidates, but full compatibility is not guaranteed. Keep a backup and test after import. Compatibility guide →

Where is my project saved?

Save to your computer to create a local file. Keep track of where your browser downloads it.

Is it safe for kids?

Read extension warnings and ask a parent or guardian before sending personal information online. Safety guide →

Does it work on phones?

G-Warp is designed for desktop use; phones are not supported yet.

What if an extension says Dangerous?

Read its warning and only enable it if you understand why it needs those capabilities. Learn about labels →

How do I report a bug?

Use the report flow or the project issue link. Include steps and expected versus actual results, but remove secrets and private information.

Can I use G-Warp projects in another editor?

Standard Scratch features are the best compatibility candidates; G-Warp-specific features may not transfer. Test the exported file in the target editor.

Who made the extensions?

Extensions can come from different creators. Check the gallery for each creator and licence. Credits and licences →

What is G-Warp?

G-Warp (short for G Wrapper) is a block-based coding app for making games, animations and music. You snap blocks together to build a project. If you've used Scratch, TurboWarp or PenguinMod, many core ideas will feel familiar. Compatibility is still being improved and should be checked project by project.

What's different is everything around the blocks. G-Warp has its own dark theme, electric C-blocks with power running through them, a mascot named G-Spark, a built-in song maker and its own panels.

Why it's being built

The future keeps moving forward and never waits. The tools we learn with should keep up with it.

Scratch, TurboWarp and PenguinMod are great, and they're where a lot of people first learned to code. G-Warp isn't trying to replace them. It aims to be a better version of what we already have: it keeps everything that works, adds what's missing and gives creators a fresh place to build.

What we're going to do

  1. Match the basics, one to one. Every block, menu and tool should work exactly the way people expect from Scratch-style editors, both in the editor and in the engine that runs projects.
  2. Make it tough. Testers try hard to break it: clone floods, huge lists, endless loops. Every crash found gets fixed, and the Bug Hunter achievement rewards whoever finds one.
  3. Build in AI. GWrap AI, an assistant inside the editor that helps you fix and improve your code. You can also connect your own AI with your own API key.
  4. Add the extras. More music tools, more extensions, more of G-Warp's own sprites and backdrops, and new ideas that only G-Warp has.
  5. Release it. When it's ready and safe, G-Warp will be shared with everyone.

The rules we build by

  • Same same, but different. It works like Scratch, TurboWarp and PenguinMod, but it has its own look. The Scratch look is only an option in Settings.
  • Theirs is theirs, ours is ours. G-Warp doesn't use anyone else's art or logos, it credits creators and it follows every licence.
  • Safety first. Any extension that can read personal information always shows a warning first. G-Warp needs no accounts, and kids under 13 need a parent's OK before any data is sent.

Where it is now

G-Warp is out as a beta, and it's the only beta for now. You can make projects and open your own, but some things may still break. GWrap AI is still in the works. Work continues on the full release, and this page will be updated as the project grows.
