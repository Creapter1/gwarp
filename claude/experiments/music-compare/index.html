What B changes: each mood has its own scale and how far the tune jumps; each theme gives the tune a shape (climb, arch, hook, falling…); each genre gets its own rhythm; changing the style changes the tune; passing notes can jump instead of only moving one step; medium parts keep half the passing notes instead of none. Same instruments, drums, bass, chords and song layout as A.
